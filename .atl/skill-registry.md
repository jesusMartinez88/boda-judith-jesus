## Compact Rules

### angular-best-practices

- Standalone components (v20+ default).
- Use `input()`, `output()`, `computed()`.
- Signals for state management.
- `inject()` for DI.
- OnPush change detection.
- Native control flow (@if, @for).
- Reactive forms.

### svg-animations

- CSS-only micro-animations for SVG.
- Use @property + @keyframes.
- `transform-box: fill-box`.
